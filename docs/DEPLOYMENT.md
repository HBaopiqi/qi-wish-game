# 部署《祈》

## 静态托管

本游戏无需构建、数据库或后端。发布目录是仓库根目录，入口为 `index.html`。可使用任意支持静态文件的 HTTPS 网站服务。

需要保留以下文件关系：

```text
qi/
├── index.html
├── styles.css
├── game.js
└── assets/
    ├── audio/
    └── images/
```

把上述文件放到服务器的 `/qi/` 目录，即可通过 `https://example.com/qi/` 游玩；放到根目录则从网站首页进入。

## GitHub Pages

如需启用 GitHub Pages，在仓库 Settings → Pages 中选择从分支发布，使用 `main` 分支和根目录 `/ (root)`。是否可用取决于仓库可见性及 GitHub 账号方案。

GitHub Pages 项目地址一般为 `https://<用户名>.github.io/<仓库名>/`。游戏使用相对资源地址，无需改写代码。提交更新后，等待 Pages 部署完成再刷新。

## 浏览器要求

- 推荐现代移动浏览器，使用竖屏。
- 首次音频播放需要玩家主动点击进入。
- 振动、全屏等功能取决于设备和浏览器支持情况。
- 保持 `.mp3`、`.ogg`、`.wav`、`.png` 和 `.json` 等资源可访问。
- 更新后遇到旧缓存时，可刷新页面或清理该站点缓存。

## 发布检查

确认首页能进入游戏、祝文与落印能继续推进、音乐配置加载成功，并检查小屏设备能滚动访问底部操作区。
