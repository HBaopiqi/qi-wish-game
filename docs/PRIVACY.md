# 游戏输入与隐私

《祈》为静态网页游戏，没有账号系统、服务端数据库或第三方分析脚本。

玩家输入的称呼与愿望使用当前标签页的 `sessionStorage` 暂存，键名为 `qi.playerName` 和 `qi.playerWish`，用于将输入融入当前游戏叙事。同一标签页刷新后可能继续保留，游戏完整结束时删除这两个键；关闭标签页通常结束该会话。

游戏代码仅请求音频配置及本地素材文件，不会通过网络发送上述输入。托管平台可能因提供网站服务而记录 IP 地址、访问时间和资源请求等标准访问日志，这些日志遵循托管平台自身的政策。

玩家可使用称呼而非真实姓名，请勿输入联系方式、身份证号或其他敏感信息。提交问题反馈时也请使用示例内容。
